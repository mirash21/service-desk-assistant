## 🎯 План улучшения качества (по приоритету)

### **Приоритет 1: Добавить keywords в metadata** (ВЫСОКИЙ)

**Проблема:** 0/100 документов имеют keywords, что делает невозможным гибридный поиск.

**Решение:** Автоматическое извлечение keywords из контента и добавление в metadata.

**Ожидаемый эффект:** +20-25% к точности поиска за счет keyword matching.

**Выполнение:**
```bash
# Тестовый режим (без изменений)
docker exec max-bot-webhook python3 /app/scripts/add_keywords_to_metadata.py

# Применение изменений
docker exec max-bot-webhook python3 /app/scripts/add_keywords_to_metadata.py --apply
```

**Пример результата:**
```python
metadata = {
    'keywords': ['принтер', 'печать', 'driver', 'драйвер', 'картридж'],
    'category': 'printers',
    'type': 'faq'
}
```

### **Приоритет 2: Разбить длинные чанки** (СРЕДНИЙ)

**Проблема:** Средняя длина чанка 1000 символов (рекомендуется 300-500).

**Решение:** 
- Для существующих данных: оставить как есть (перегенерация embeddings дорогая)
- Для новых данных: использовать chunk_size=400 с overlap=50

**Ожидаемый эффект:** +10-15% к релевантности результатов.

**Рекомендация для будущих обновлений:**
```python
def create_optimal_chunks(text, chunk_size=400, overlap=50):
    """Создает чанки с перекрытием для сохранения контекста"""
    chunks = []
    start = 0
    
    while start < len(text):
        end = start + chunk_size
        
        # Находим границу предложения
        if end < len(text):
            sentence_end = text.rfind('.', start, end)
            if sentence_end > start:
                end = sentence_end + 1
        
        chunk = text[start:end].strip()
        if chunk:
            chunks.append(chunk)
        
        start = end - overlap  # Перекрытие
    
    return chunks
```

### **Приоритет 3: Добавить синонимы в тексты** (СРЕДНИЙ)

**Проблема:** Только 7% документов содержат синонимы.

**Решение:** При создании новых Q&A добавлять синонимы в скобках.

**Примеры:**
```
❌ Было: "Введите пароль"
✅ Стало: "Введите пароль (password, пин-код)"

❌ Было: "Подключите принтер"
✅ Стало: "Подключите принтер (печатное устройство, МФУ)"

❌ Было: "Перезагрузите компьютер"
✅ Стало: "Перезагрузите компьютер (ПК, ноутбук, workstation)"
```

**Ожидаемый эффект:** +15-20% к охвату различных формулировок пользователей.

### 1. **Использовать overlapping chunks**


**Преимущество:** Каждое предложение входит в 2 чанка, сохраняется контекст.
