# Обработка изображений с классификацией намерений

## Обзор

Бот теперь поддерживает интеллектуальную обработку изображений с автоматической классификацией намерений пользователя. При получении фотографии бот анализирует содержимое через Yandex Vision API и определяет, хочет ли пользователь задать вопрос по изображению или сообщить о проблеме.

## Архитектура обработки

```
Пользователь отправляет фото
         ↓
Загрузка изображения (download_file)
         ↓
Анализ через Yandex Vision API (analyze_image)
         ↓
Извлечение: IMAGE_TEXT + IMAGE_DESCRIPTION
         ↓
Классификация намерения (_classify_intent)
         ↓
    ┌────┴─────┐
    ↓          ↓
image_question  ticket_creation
    ↓          ↓
_handle_   _create_
image_     ticket
question
```

## Классификация намерений для изображений

### Типы намерений

1. **`image_question`** - вопрос по содержимому изображения
2. **`ticket_creation`** - сообщение о проблеме, видимой на фото
3. **`question`** - обычный текстовый вопрос (если есть текст вместе с фото)

### Критерии классификации

#### image_question (вопрос по изображению)
- Ключевые слова: "что это", "что здесь", "что написано", "прочитай", "переведи", "распознай текст", "что на фото", "что на картинке"
- Глаголы: "посмотри", "посмотрите", "видишь", "видите", "распознай"
- Только изображение без текста или очень короткий текст (< 10 символов)

#### ticket_creation (создание задачи)
- Ключевые слова проблем: "не работает", "сломалось", "ошибка", "баг", "поломка"
- Явный запрос: "создай задачу", "зарегистрируй инцидент"
- Описание проблемы с изображением как доказательством

```

Это означает, что запрашиваемая страница не найдена. Попробуйте 
проверить URL или обновить страницу. Если проблема повторяется, 
создайте задачу командой 'создай задачу'."
```

### Сценарий 2: Распознавание текста
```
Пользователь: [фото документа] "Прочитай текст"

Бот анализирует:
- IMAGE_TEXT: "Инструкция по настройке VPN..."
- IMAGE_DESCRIPTION: "document with text"

Ответ бота:
"На изображении видна инструкция по настройке VPN. Текст содержит

с настройкой VPN, я могу создать задачу для ИТ-специалиста."
```

### Сценарий 3: Проблема на фото
```
Пользователь: [фото сломанного принтера] "Принтер не работает, бумага замята"

Бот классифицирует: ticket_creation (ключевые слова "не работает")

Ответ бота:
"Спасибо за обращение! Зарегистрирована заявка: 'Принтер не работает, 
замятие бумаги'. Приоритет: средний. Ожидайте решения в течение 4 часов."
```

### Сценарий 4: Только фото без текста
```
Пользователь: [фото монитора с синим экраном]

Бот классифицирует: image_question (нет текста, только изображение)

Ответ бота:
"На изображении виден синий экран смерти (BSOD) Windows. Это критическая 
ошибка системы. Пожалуйста, перезагрузите компьютер. Если ошибка

```

### 3. Обработка вопроса по изображению

```python
async def _handle_image_question(self, context: str, chat_id: str, user_id: str):
    prompt = f"""Ты — ИТ-ассистент с возможностью анализа изображений.

Контекст изображения:
{context}

Проанализируй содержимое и ответь на вопрос:
1. Используй IMAGE_TEXT если есть
2. Учитывай IMAGE_DESCRIPTION
3. Опиши проблему если видна
4. Предложи решение или создание задачи"""
    
    answer = self.yandex_ai.generate_text(prompt)
    return {"chat_id": chat_id, "text": answer}
```
