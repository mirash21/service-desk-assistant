# Исправление обработки изображений в attachments

## Проблема

При отправке изображения через MAX Messenger бот отвечал:
```
❌ Не удалось распознать речь. Попробуйте отправить текстовое сообщение или запишите голосовое сообщение четче.
```

## Причина

MAX API отправляет **и фото, и аудио** в одном поле `attachments`, но код обрабатывал ВСЕ вложения как аудио (MP3), пытаясь распознать речь через STT API.

**Структура webhook от MAX API:**
```json
{
  "message": {
    "body": {
      "text": "у меня компьютер сломался",
      "attachments": [
        {
          "payload": {
            "photo_id": 15953558588,  // ← Это фото!
            "url": "https://i.oneme.ru/i?r=..."
          }
        }
      ]
    }
  }
}
```

Код пытался скачать это фото как MP3 и отправить в Yandex STT → ошибка "Failed to parse audio for specified audio format".

## Решение

### 1. Определение типа вложения

Добавлена проверка типа вложения по полям в `payload`:

```python
# Определяем тип вложения
is_photo = "photo_id" in payload or "photo" in payload
is_audio = "audio_id" in payload or "voice" in payload or "duration" in payload
```

### 2. Условная обработка

```python
if url and is_photo:
    # Скачиваем как JPG и анализируем через Vision API
    photo_path = await download_file(url, {}, "jpg")
    vision_result = self.yandex_ai.analyze_image(photo_path)
    # Добавляем IMAGE_TEXT и IMAGE_DESCRIPTION в контекст
    
elif url and is_audio:
    # Скачиваем как MP3 и распознаем через STT
    audio_path = await download_file(url, {}, "mp3")
    text_from_voice = self.yandex_ai.speech_to_text(audio_path)
    # Добавляем VOICE_TEXT в контекст
    
elif url:
    # Неизвестный тип - пробуем как аудио (обратная совместимость)
    ...
```

### 3. Удаление дублирующегося кода

Удалена старая обработка `message.get("photo")`, так как MAX API всегда отправляет фото в `attachments`.

## Примеры работы

### Сценарий 1: Фото с текстом
```
Пользователь: [фото ошибки на экране] "у меня компьютер сломался"

Логика:
1. attachment имеет photo_id → is_photo=True
2. Скачиваем как JPG
3. Анализируем через Yandex Vision
4. Классифицируем намерение: ticket_creation (ключевое слово "сломался")
5. Создаем задачу с описанием проблемы и содержимым фото

Ответ бота:
"Спасибо за обращение! Зарегистрирована заявка: 'Компьютер сломался'. 
На изображении видна ошибка системы. Приоритет: высокий. 
Ожидайте решения в течение 1 часа."
```

### Сценарий 2: Только фото с вопросом
```
Пользователь: [фото принтера] "Что это?"

Логика:
1. attachment имеет photo_id → is_photo=True
2. Скачиваем и анализируем
3. Классифицируем: image_question (короткий текст + ключевое слово "что")
4. Отвечаем на вопрос по изображению

Ответ бота:
"На изображении виден сетевой принтер HP LaserJet. 
Если у вас проблемы с печатью, опишите проблему подробнее 
или создайте задачу командой 'создай задачу'."
```

### Сценарий 3: Голосовое сообщение
```
Пользователь: [аудио] "Принтер не работает"

Логика:
1. attachment имеет duration/audio_id → is_audio=True
2. Скачиваем как MP3
3. Распознаем через STT
4. Классифицируем: ticket_creation ("не работает")
5. Создаем задачу

Ответ бота:
"Спасибо за обращение! Зарегистрирована заявка: 'Принтер не работает'. 
Приоритет: средний. Ожидайте решения в течение 4 часов."
```
