# Guidelines: Добавление новых документов в RAG базу знаний

**Версия:** 1.0  
**Дата:** 27 апреля 2026  
**Статус:** ✅ Обязательно к исполнению

---

## 🎯 Цель

Предотвратить повторение критических проблем при добавлении новых документов:
- ❌ Отсутствующие keywords в metadata
- ❌ Слишком длинные чанки (>600 символов)
- ❌ Отсутствие синонимов
- ❌ Отсутствие категорий
- ❌ Неформатированный текст (не Q&A)

---

## 📋 Чеклист перед добавлением документа

### ✅ Обязательные требования:

1. **Формат Q&A**
   ```
   В: [Вопрос пользователя естественным языком]
   О: [Ответ с пошаговым решением]
      • Шаг 1
      • Шаг 2
      • Шаг 3
   ```

2. **Длина чанка: 200-600 символов** (оптимально 400)
   - Если текст длиннее → разбить на несколько чанков
   - Каждый чанк должен быть самодостаточным

3. **Наличие синонимов** для ключевых терминов
   ```
   ❌ "Введите пароль"
   ✅ "Введите пароль (password, пин-код)"
   
   ❌ "Подключите принтер"
   ✅ "Подключите принтер (печатное устройство, МФУ)"
   ```

4. **Контекстный заголовок** (если чанк часть большой темы)
   ```
   Устранение неполадок принтера - Принтер не печатает:
   В: Что делать если принтер не печатает?
   О: ...
   ```

5. **Metadata обязательно должны включать:**
   ```python
   metadata = {
       'type': 'faq',  # или 'guide', 'troubleshooting'
       'format': 'qa',
       'category': 'printers',  # из списка категорий ниже
       'keywords': ['принтер', 'печать', 'driver']  # автоматически добавятся
   }
   ```

## 🔧 Автоматизированный процесс добавления

### Способ 1: Использование SafeDocumentManager (РЕКОМЕНДУЕТСЯ)

```python
from utils.safe_document_manager import SafeDocumentManager

manager = SafeDocumentManager()

# Добавление одной Q&A пары
result = manager.add_qa_pair_safe(
    question="Как подключить принтер?",
    answer="Подключите принтер (печатное устройство, МФУ) к компьютеру через USB кабель.",
    category="printers",  # опционально, определится автоматически
    auto_fix=True  # автоматически добавит keywords, синонимы, категорию
)

print(result)
# {'success': True, 'document_id': '...', 'metadata': {...}}
```

**Преимущества:**
- ✅ Автоматически добавляет keywords
- ✅ Определяет категорию
- ✅ Предлагает синонимы
- ✅ Разбивает длинные чанки
- ✅ Валидирует формат Q&A

### Способ 2: Пакетное добавление

```python
documents = [
    {
        'content': 'В: Как настроить Wi-Fi?\nО: Откройте настройки сети...',
        'metadata': {'category': 'network'}
    },
    {
        'content': 'В: Как сбросить пароль?\nО: Нажмите Ctrl+Alt+Del...',
        'metadata': {'category': 'password'}
    }
]

result = manager.batch_add_documents_safe(documents, auto_fix=True)
print(f"Успешно: {result['success']}/{result['total']}")
```

### Способ 3: Предварительная валидация

```python
# Проверить документ перед добавлением
validation = manager.validate_before_add(content, metadata)

print(validation['validation_report'])
# Покажет все проблемы и рекомендации

if validation['score'] >= 80:
    # Можно добавлять
    manager.add_document_safe(content, metadata, auto_fix=True)
else:
    # Нужно исправить проблемы
    print("Документ требует доработки")
```

## 📂 Список категорий

Используйте эти категории для `metadata['category']`:

| Категория | Ключевые слова | Примеры |
|-----------|----------------|---------|
| `printers` | принтер, печать, driver, картридж, МФУ | Настройка принтера, замена картриджа |
| `network` | сеть, wi-fi, internet, router, vpn | Подключение к Wi-Fi, настройка VPN |
| `email` | почта, email, outlook, письмо, вложение | Настройка Outlook, отправка письма |
| `password` | пароль, password, пин-код, сброс, учетная запись | Сброс пароля, смена PIN |
| `software` | программа, установка, обновление, лицензия | Установка ПО, обновление Windows |
| `hardware` | компьютер, ноутбук, монитор, клавиатура | Замена комплектующих, диагностика |
| `security` | вирус, антивирус, firewall, безопасность | Удаление вируса, настройка firewall |
| `windows` | windows, ошибка, синий экран, bsod | Исправление ошибок Windows |
| `office` | word, excel, powerpoint, office | Работа с документами Office |
| `crm` | crm, клиент, сделка, контрагент | Работа с CRM системой |
| `mobile` | телефон, android, ios, смартфон | Настройка мобильного устройства |
| `general` | общие вопросы, помощь | Общие вопросы поддержки |

## 💡 Примеры хороших документов

### ✅ Пример 1: Идеальный документ

```python
content = """Устранение неполадок принтера - Принтер не печатает:

В: Что делать если принтер (печатное устройство, МФУ) не печатает?

О: Выполните следующие шаги:
• Проверьте подключение кабеля USB или сети Wi-Fi
• Откройте Панель управления → Устройства и принтеры
• Убедитесь что принтер установлен как устройство по умолчанию
• Проверьте очередь печати и удалите зависшие задания
• Перезапустите службу печати (Print Spooler)
• Переустановите драйвер (driver) принтера с официального сайта"""

metadata = {
    'type': 'troubleshooting',
    'format': 'qa',
    'category': 'printers',
    'keywords': ['принтер', 'печать', 'driver', 'картридж', 'USB']
}
```

**Почему это хорошо:**
- ✅ Формат Q&A
- ✅ Длина ~450 символов (оптимально)
- ✅ Есть синонимы: "принтер (печатное устройство, МФУ)"
- ✅ Контекстный заголовок
- ✅ Полные metadata с keywords
- ✅ Четкая категория

content = """В: Как сбросить пароль (password, пин-код) учетной записи?

## ❌ Примеры плохих документов (НЕ ДЕЛАЙТЕ ТАК)

### ❌ Проблема 1: Нет формата Q&A

```python
# ПЛОХО:
content = "Чтобы подключить принтер, нужно установить драйверы и проверить подключение."

# ХОРОШО:
content = """В: Как подключить принтер?
О: Установите драйверы (driver) с диска или сайта производителя. 
   Проверьте подключение кабеля USB."""
```

### ❌ Проблема 2: Слишком длинный чанк

```python
# ПЛОХО: 1200 символов в одном чанке
content = "Очень длинный текст с множеством шагов..." * 20

# ХОРОШО: Разбить на 3 чанка по 400 символов
chunk_1 = "В: Часть 1 - Начальная настройка...\nО: ..."
chunk_2 = "В: Часть 2 - Подключение...\nО: ..."
chunk_3 = "В: Часть 3 - Тестирование...\nО: ..."
```

### ❌ Проблема 3: Нет синонимов

```python
# ПЛОХО:
content = "В: Как ввести пароль?\nО: Введите пароль в поле ввода."

# ХОРОШО:
content = "В: Как ввести пароль (password, пин-код)?\nО: Введите пароль в поле ввода."
```

### ❌ Проблема 4: Нет metadata

```python
# ПЛОХО:
metadata = {}

# ХОРОШО:
metadata = {
    'type': 'faq',
    'format': 'qa',
    'category': 'password',
    'keywords': ['пароль', 'password', 'ввод']
}
```

## 🔍 Troubleshooting

### Проблема: "Документ не прошел валидацию"

**Решение:**
```python
# Посмотрите отчет о валидации
validation = manager.validate_before_add(content, metadata)
print(validation['validation_report'])

# Исправьте указанные проблемы
# Или включите auto_fix=True для автоматического исправления
```

### Проблема: "Слишком длинный чанк"

**Решение:**
```python
# SafeDocumentManager автоматически разобьет на части
result = manager.add_document_safe(long_content, metadata, auto_fix=True)
# Результат: несколько документов вместо одного
```

### Проблема: "Не могу определить категорию"

**Решение:**
```python
# Укажите категорию вручную
metadata['category'] = 'printers'  # из списка категорий

# Или используйте auto_fix=True для автоматического определения
```

## 📝 Checklist для code review

При ревью кода добавления документов проверяйте:

- [ ] Используется `SafeDocumentManager` или аналогичная валидация
- [ ] `auto_fix=True` включен для автоматических исправлений
- [ ] Контент в формате Q&A
- [ ] Длина чанка 200-600 символов
- [ ] Есть синонимы для ключевых терминов
- [ ] Metadata содержат category и type
- [ ] Проведена предварительная валидация для сложных случаев
