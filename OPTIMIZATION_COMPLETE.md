## 🔧 Дополнительные шаги (рекомендуется)

### Выполните SQL скрипт для создания индексов:

1. Откройте **Supabase Dashboard → SQL Editor**
2. Скопируйте содержимое файла `check_chat_history_indexes.sql`
3. Нажмите **Run**

Это создаст индексы для ускорения запросов:
```sql
CREATE INDEX idx_chat_history_user_id ON chat_history(user_id);
CREATE INDEX idx_chat_history_created_at ON chat_history(created_at DESC);
CREATE INDEX idx_chat_history_user_time ON chat_history(user_id, created_at DESC);
```
