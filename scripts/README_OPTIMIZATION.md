# Скрипты оптимизации качества RAG базы знаний

Эта папка содержит скрипты для анализа и улучшения качества базы знаний RAG сервис-деск ассистента.

## 📋 Проблемы которые решают скрипты

Согласно рекомендациям системы анализа:

1. **36 чанков слишком длинные** (>600 симв.) - нужно разделить
2. **5 чанков короткие** (<200 симв.) - нужно объединить или расширить
3. **Только 64% документов имеют категории** - нужно добавить категории

## 🛠️ Доступные скрипты

### 1. `comprehensive_rag_analysis.py` - Комплексный анализатор

Полный анализ качества базы знаний с генерацией отчета.

**Использование:**
```bash
# Анализ образца (100 документов)
python3 scripts/comprehensive_rag_analysis.py

# Полный анализ (все документы)
python3 scripts/comprehensive_rag_analysis.py --full
```

**Что делает:**
- Анализирует длины всех чанков
- Проверяет наличие категорий
- Проверяет наличие keywords
- Проверяет формат Q&A
- Генерирует отчет с оценкой качества (0-100)
- Сохраняет отчет в файл
- Показывает команды для исправления проблем

---

### 2. `optimize_chunk_lengths.py` - Оптимизация длин чанков

Разделяет длинные чанки и объединяет короткие.

**Использование:**
```bash
# Тестовый режим (без изменений)
python3 scripts/optimize_chunk_lengths.py

# Применение изменений
python3 scripts/optimize_chunk_lengths.py --apply
```

**Что делает:**
- Находит чанки длиннее 600 символов
- Разбивает их на части по ~400 символов с перекрытием 50 символов
- Находит чанки короче 200 символов
- Объединяет соседние короткие чанки одной категории
- Сохраняет metadata и keywords при модификации

**Алгоритм разделения длинных чанков:**
```
Исходный чанк (1000 симв.):
"Вопрос... Ответ... Продолжение..."

↓ Разделение с overlap=50

Чанк 1 (400 симв.): "Вопрос... Ответ..."
Чанк 2 (400 симв.): "...Ответ... Продолжение..."
Чанк 3 (250 симв.): "...Продолжение..."
```

**Алгоритм объединения коротких чанков:**
```
Короткий чанк 1 (150 симв., категория: printers)
Короткий чанк 2 (120 симв., категория: printers)

↓ Объединение

Объединенный чанк (270 симв., категория: printers)
```

### 3. `add_categories_to_documents.py` - Добавление категорий

Автоматически определяет и добавляет категории для документов.

**Использование:**
```bash
# Тестовый режим (без изменений)
python3 scripts/add_categories_to_documents.py

# Применение изменений
python3 scripts/add_categories_to_documents.py --apply
```

**Что делает:**
- Находит документы без категории или с category='unknown'
- Анализирует содержимое документа
- Определяет категорию на основе ключевых слов
- Обновляет metadata с правильной категорией

**Поддерживаемые категории:**
- `printers` - принтеры, печать, драйверы
- `network` - сеть, Wi-Fi, интернет, VPN
- `email` - почта, Outlook, вложения
- `password` - пароли, учетные записи, сброс
- `software` - программы, установка, обновления
- `hardware` - компьютеры, ноутбуки, периферия
- `security` - вирусы, антивирусы, безопасность
- `windows` - ошибки Windows, обновления
- `office` - Word, Excel, PowerPoint
- `crm` - CRM, клиенты, сделки
- `mobile` - телефоны, планшеты, Android, iOS

## 🔧 Технические детали

### Перекрытие чанков (Overlap)

При разделении длинных чанков используется overlap=50 символов.

**Зачем это нужно:**
- Каждое предложение входит в 2 чанка
- Сохраняется контекст между чанками
- Улучшается точность поиска

**Пример:**
```
Чанк 1: "...принтер не печатает. Проверьте подключение."
Чанк 2: "Проверьте подключение. Перезапустите службу печати."
                          ^^^^^^^^^^^^^^^^^^^^^^^^
                          Эта фраза есть в обоих чанках
```

### Определение категорий

Категории определяются на основе частоты ключевых слов в тексте.

**Алгоритм:**
1. Для каждой категории есть список keywords
2. Подсчитывается сколько keywords из каждой категории найдено в тексте
3. Выбирается категория с максимальным количеством совпадений
4. Если совпадений нет - категория остается 'unknown'

**Пример:**
```python
Текст: "Принтер не печатает. Установите driver с диска."

Категория 'printers': найдено 3 keywords (принтер, печать, driver)
Категория 'hardware': найдено 0 keywords
Категория 'software': найдено 1 keyword (driver)

→ Выбрана категория: 'printers'
```

## 🐛 Решение проблем

### Ошибка подключения к базе данных

```
Error: Could not connect to Supabase
```

**Решение:**
1. Проверьте файл `.env`
2. Убедитесь что `SUPABASE_URL` и `SUPABASE_KEY` правильные
3. Проверьте подключение к интернету

### Ошибка при обновлении документов

```
Error updating document: ...
```

**Решение:**
1. Проверьте права доступа к таблице `documents`
2. Убедитесь что service role key имеет права на запись
3. Проверьте логи Supabase

### Категории не определяются

**Решение:**
1. Проверьте содержимое документа - возможно оно слишком короткое
2. Добавьте больше тематических keywords в `CATEGORY_KEYWORDS` в `document_validator.py`
3. Вручную установите категорию через Admin Panel
