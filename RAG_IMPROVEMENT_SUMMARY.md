## 🔍 Найденные проблемы и решения

### Проблема 1: ❌ Мало синонимов (4%)

**Влияние:** Пропуск релевантных запросов с альтернативными формулировками.

**Рекомендация:** При создании новых Q&A добавлять синонимы:
```
❌ "Введите пароль"
✅ "Введите пароль (password, пин-код)"

❌ "Подключите принтер"
✅ "Подключите принтер (печатное устройство, МФУ)"
```

**Ожидаемый эффект:** +15-20% к охвату запросов.

---

### Проблема 2: ⚠️ Длинные чанки (803 символа)

**Влияние:** Снижение точности семантического поиска.

**Рекомендация для новых данных:**
```python
def create_optimal_chunks(text, chunk_size=400, overlap=50):
    """Создает чанки с перекрытием"""
    # Реализация с overlapping chunks
```

**Для существующих данных:** Оставить как есть (перегенерация embeddings дорогая).

**Ожидаемый эффект:** +10-15% к релевантности для новых данных.

---

### Проблема 3: ⚠️ Изолированные чанки (42%)

**Влияние:** Потеря контекста при поиске.

**Рекомендация:** Добавлять заголовки/контекст к чанкам:
```
❌ "• Проверьте очередь печати..."

✅ "Устранение неполадок принтера - Принтер не печатает:
    • Проверьте очередь печати..."
```

**Ожидаемый эффект:** +5-10% к точности понимания контекста.

---

### Проблема 4: ⚠️ Недостаточно категорий (25%)

**Влияние:** Невозможность фильтрации по темам.

**Решение:** Можно расширить скрипт `add_keywords_to_metadata.py` для автоматической категоризации на основе keywords.

## 💡 Технические рекомендации

### Для гибридного поиска:

Теперь, когда keywords добавлены, можно использовать hybrid_search:

```python
from rag.supabase_manager import SupabaseManager

manager = SupabaseManager()

# Гибридный поиск с keywords
results = manager.hybrid_search(
    query="не работает принтер",
    top_k=5,
    min_similarity=0.5
)

# Результаты будут включать как semantic, так и keyword matches
for doc in results:
    print(f"Type: {doc.get('search_type')}, Score: {doc.get('combined_score')}")
```

### Для мониторинга:

```python
# Анализ unanswered questions
from utils.unanswered_analyzer import analyze_unanswered_questions

stats = analyze_unanswered_questions('data/unanswered_questions.json')
print(f"Total unanswered: {stats['total']}")
print(f"Top topics: {stats['top_topics'][:5]}")
```
